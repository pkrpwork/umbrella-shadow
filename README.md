# umbrella-shadow

เว็บจำลองตำแหน่งเงาของร่มสนาม (ร่มราบแนวระดับ) ตามตำแหน่งดวงอาทิตย์ — กรอกละติจูด/ลองจิจูด วันที่ เวลา รัศมีและความสูงร่ม แล้วดูเงาแบบภาพนิ่งหรือ Animation ตลอดวัน

ใช้สูตรดาราศาสตร์มาตรฐาน (เดคลิเนชัน, มุมชั่วโมง, สมการเวลา, มุมเงย/มุมทิศ) อ้างอิงเส้นเมริเดียน 105°E

มีลูกโลกแสดงจุดที่ดวงอาทิตย์อยู่เหนือศีรษะ เส้นแบ่งกลางวัน/กลางคืน และเส้นทางของดวงอาทิตย์ตลอดวัน (ใช้ d3-geo + world-atlas จาก CDN)

## ใช้งาน
เปิดผ่าน GitHub Pages หรือเปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ทดสอบ
`node test.js` เทียบสูตรกับค่าที่คำนวณจากโปรแกรม Python ต้นฉบับ (`ref.json`, 200 กรณี)

## เครดิต
แนวคิดและโปรแกรมต้นฉบับ (Python/Tkinter) โดยเพื่อนของผู้พัฒนา — เว็บนี้เขียนใหม่ทั้งหมดด้วย HTML/JavaScript
